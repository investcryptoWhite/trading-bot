## ⚙️ Funcționalități

- ✅ Date live de pe Binance (fără cheie API)
- ✅ Semnal agregat BUY / SELL / NEUTRU
- ✅ Calculator leverage, preț intrare, profit dorit
- ✅ Preț de ieșire automat calculat
- ✅ Preț de lichidare estimat
- ✅ Notificări push pe telefon prin **ntfy**
- ✅ Auto-refresh configurabil
- ✅ Funcționează pe telefon, tabletă și PC

## 🔔 Notificări ntfy

1. Instalează aplicația **ntfy** pe telefon (App Store / Google Play)
2. Creează un topic secret (ex: `beatbot-alex-2847x`)
3. Abonează-te la topic în aplicație
4. Introdu topicul în câmpul din bot
5. Primești notificări la fiecare semnal BUY/SELL
